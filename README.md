# chungquantin

Personal portfolio and writing site for Tin Chung.

The primary experience is a light, typography-led editorial portfolio with a selected work index, writing archive, metadata/OG routes, RSS, and sitemap support. The previous ChaseOS interactive desktop interface is preserved as an archive at `/os`.

## Development

```bash
pnpm install
pnpm dev
```

## Verification

```bash
pnpm build
```

## Routes

- `/` - editorial portfolio homepage
- `/os` - archived ChaseOS desktop interface
- `/blog` - writing index
- `/blog/[slug]` - individual posts
- `/rss` - RSS feed
- `/sitemap.xml` - sitemap
- `/og` - dynamic Open Graph image
